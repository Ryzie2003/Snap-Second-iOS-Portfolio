# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials, personal media, or customer information in a public GitHub issue.

Report security concerns privately through the [Snap Second contact form](https://www.snapsecond.co/contact). Include a concise description, affected component, reproduction steps, and impact. Do not access, modify, or retain data that does not belong to you while investigating.

## Portfolio configuration

This public portfolio intentionally excludes production Firebase configuration, analytics identifiers, licensed production audio, signing material, and private media. Contributors should use their own development services and keep local configuration out of Git.
